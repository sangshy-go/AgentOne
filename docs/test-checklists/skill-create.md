# Skill 创建页测试清单

每次改动 Skill 创建页后，必须逐项测试。

## 核心流程

### 1. 文件夹上传
- [ ] 选择文件夹 → 文件树展示（按层级，可展开/折叠）
- [ ] 点击文件名 → 右侧预览内容
- [ ] 点击文件夹 → 展开/折叠
- [ ] SKILL.md 自动解析 → 表单回填 name/description/body/category
- [ ] 编辑表单字段 → 预览区不同步（预期行为）
- [ ] 点击"重新选择" → 清空文件树和预览
- [ ] 发布成功

### 2. zip 压缩包上传
- [ ] 上传 zip → 前端解压 → 文件树展示
- [ ] 剥离公共根目录（SKILL.md 在根）
- [ ] 点击文件 → 预览内容
- [ ] SKILL.md 自动解析 → 表单回填
- [ ] zip 内无 SKILL.md → 提示"请手动填写"
- [ ] zip 格式错误 → 提示"解压失败"
- [ ] 发布成功

### 3. 单文件 md 上传
- [ ] 上传 .md 文件 → 解析 frontmatter
- [ ] 表单回填 name/description/body/category
- [ ] 文件树显示 SKILL.md
- [ ] 点击 SKILL.md → 预览内容
- [ ] 发布成功

### 4. 粘贴 SKILL.md
- [ ] 粘贴完整 SKILL.md（含 frontmatter）→ 点击"解析"
- [ ] 表单回填
- [ ] 文件树显示 SKILL.md
- [ ] 预览内容
- [ ] 发布成功

### 5. 脚本包创建
- [ ] 填写表单 → 添加脚本文件夹
- [ ] 文件树展示（SKILL.md 由表单生成 + 附加文件）
- [ ] 点击文件 → 预览
- [ ] 点击删除按钮 → 移除文件
- [ ] 发布成功

## 边界情况

### 文件预览
- [ ] 文本文件（md/py/js/json）→ 正常预览
- [ ] 二进制文件（png/jpg/zip）→ 提示"暂不支持预览"
- [ ] 大文件（>1MB）→ 预览不卡顿
- [ ] 空文件 → 预览显示空内容

### 文件树
- [ ] 深层嵌套（scripts/utils/helper.py）→ 正确展示层级
- [ ] 文件名含特殊字符（空格、中文）→ 正常显示
- [ ] 删除当前预览的文件 → 预览区清空
- [ ] 重新选择文件夹 → 预览区清空

### 表单联动
- [ ] 编辑 name/description/category → 不影响预览
- [ ] 编辑 body（技能正文）→ 不影响预览（预览的是原 SKILL.md）
- [ ] 预览区是只读的（不能在预览里编辑）

## 发布验证

- [ ] 发布后到 Skill 中心查看
- [ ] 名称、描述、工种正确
- [ ] 技能正文正确
- [ ] 包文件列表正确（如果有）

## 发现问题后

1. 立即修复
2. 加测试用例（如果是 E2E 可覆盖的场景）
3. 更新本清单（如果是新的边界情况）
