## 发现并修复的问题

| # | 问题 | 修复 |
|---|------|------|
| 1 | `file://` 下 `history.replaceState` 触发安全警告 | try/catch 包裹，忽略受限环境 |
| 2 | toggle 开关宽度为 0（label 默认 inline，width 不生效） | `.toggle` 增加 `display:inline-block` |
| 3 | a11y：筛选 select / 搜索框无 label | 补 `aria-label` |
